//!

//! - **Variable map** — [`Engine::evaluate`]: references are looked up in a
34
//!   `HashMap<String, Value>`. Suitable for ad-hoc formula evaluation outside a

//!   workbook.

//! - **Resolver** — [`Engine::evaluate_with_resolver`]: every cell, range, and
